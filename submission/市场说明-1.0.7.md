# 市场说明 — dsh-whale-glance 1.0.7

写于 2026-11-22 07:10（北京）。上一份 `市场说明-1.0.6.md` 里的字段结论仍然成立，这份只更新「现在是什么状态、这版多了什么、发布前后各做什么」。

## 结论

- **市场条目不用改**。`submission/entry.yml` 一个字都不动：上游条目 schema 只认 `url / name / category / description / icon / tarball / file`，`npm` 和 `version` 由探针夜间从 registry 自动映射，手写会被 pr-check 判成 unknown field 拒掉（依据见 `市场说明-1.0.6.md` 第 2、3 节，原文与行号都在）。
- **1.0.7 还没发**。registry 线上 latest 是 `1.0.6`（2026-11-19T19:43Z），本地已经升到 `1.0.7`，等她点头再 `npm publish`。
- 发布之后市场页的 install 命令会变成 `dsh plugin --profile web add dsh-whale-glance`，版本号随下一次夜间探针（cron `23 2 * * *` UTC，北京每天 10:23）自动更新，不需要提 PR、不需要通知上游。

## 这版改了什么（1.0.6 → 1.0.7）

| 改动 | 她报的问题 / 起因 |
| --- | --- |
| 字幕窗「最近三条」改成逐条延迟出现 | 每次发话字幕窗一下弹三格，看着像卡了一下全冒出来 |
| 档案不再依赖「当场发话」；`SEG_MIN_LINES` 3→2；新的 `lib/segment-rules.js` 收口所有门槛 | 一场只说了 2 句就白说，`shows.json` 一直不长 |
| 画中画 / 播放器窗口的守门放宽 | 左半边画中画、右半边嘉立创EDA 时，前台永远不是播放器，每 6 秒白丢一帧，整场不开口 |
| 许可补齐：`LICENSE-APACHE` 随包、NOTICE 写上游版权行与改动清单 | Apache-2.0 比对发现抓屏/判分是衍生代码，原来的署名不够 |
| 发版门禁 `scripts/release-gate.mjs` | 发版前要一条命令查完语法/自检/单测/打包清单/冷装/版本/registry/git |
| `lib/segment-rules.js` 进 `files` | 门禁第一次跑就抓到：不在名单里，别人装上的包会 import 崩 |

打包口径没变的：MIT 为主，抓屏/判分那部分按 Apache-2.0（见 `NOTICE` / `LICENSE-APACHE`）；包内文件从 15 个变 17 个（多了 `lib/segment-rules.js` 和 `LICENSE-APACHE`）。

## 发布前（已经能自动跑的部分）

```
node scripts/release-gate.mjs
```

八项：语法、`tests/preflight.mjs`、三套单测、`npm pack` 清单、真 pack 并冷装 import、三处版本一致 + registry 比对、仓库与运行目录哈希、git 状态。
`--quick` 跳过冷装。

这条命令在 1.0.7 上跑过，除「运行时哈希」（运行目录还是旧代码）外全绿。registry 那项现在会显示线上 1.0.6 < 本地 1.0.7，属于可发状态。

## 发布当天（要她点头才做）

1. `.npmrc` 里那个 npm token 换新（旧的要确认还活着）。
2. `npm publish`（会自动跑 `prepublishOnly` 无；包内 `files` 已核对）。
3. 发完 `npm view dsh-whale-glance version` 应为 `1.0.7`；`npm pack` 的 tgz 与包内清单留档在 `D:\小气泡\余光-发版存档点-2026-11-22.md`。
4. `git push origin master:main`（本地叫 master、远端叫 main，直接 push 会推错）。
5. 把 `lib/index.js`、`lib/segment-rules.js`、`helper/sense.py`、`package.json`、`LICENSE-APACHE`、`NOTICE` 拷到运行目录，重启 DSH 后真机验（只有她能验的部分见验收清单）。

## 没做的

- README 里没有逐版本 changelog 章节，1.0.7 的变化只写在这份和 git 提交里。
- `package.json` 的 `license` 字段仍是整包口径 `MIT`，Apache 部分靠 `NOTICE` 说明边界；要改成 `MIT AND Apache-2.0` 得她定，会影响市场页显示。
- 市场页截图与描述没动：这版没有改界面。
