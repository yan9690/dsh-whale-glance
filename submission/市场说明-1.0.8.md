# 市场说明 — dsh-whale-glance 1.0.8

写于 2026-11-23 23:10（北京）。上一份 `市场说明-1.0.7.md` 里的字段结论、发布流程照旧成立，这份只写「1.0.8 改了哪几处、为什么改、发之前查过什么」。

## 结论

- **市场条目不用改**。`submission/entry.yml` 一个字都不动；`npm` 与 `version` 由上游探针从 registry 自动映射，手写会被 pr-check 判成 unknown field。
- **1.0.7 已经发出去了**。registry 线上 latest 是 `1.0.7`（2026-11-22T10:47:07Z），本地升起 `1.0.8`，等她点头再 `npm publish`。
- 这次没有新配置项、没有数据迁移；`config.json` / `games-notes.json` / `shows.json` / `plays/` 都在 `%DSH_HOME%\storages\whale-glance\`，不在包目录里，覆盖升级碰不到它们。

## 这版改了什么（1.0.7 → 1.0.8）

| 改动 | 起因 |
| --- | --- |
| 语音失败不再静默：写 `tts-error.log`，开机自检后端，`/state` 带 `voice` 字段，面板语音行下面加一行提示 | 语音坏的时候只有「怎么没声了」这一条线索。最可能的坏法是 DSH 更新运行时把 pip 装的 `edge_tts` 清掉，那时每句都失败、每处都 `catch` 掉，查起来全靠猜 |
| 「最近说过什么」按窗口分开记（进程内，窗口标题做键） | 以前读 `chat-history.txt` 尾部，那份是整天混在一起的；从游戏切到番剧，上一场的句子还在「别重复」里压着，新场景开头就憋住 |
| 拼图提示词去掉「第 N 帧」和逐帧时间戳，改成「约 N 秒里的几个瞬间」 | 提示词里写着帧序，模型就学着自己说「第3帧里…」，那不是给用户听的话 |
| 沉默判定补上「没什么想说的」 | 提示词让它画面空时说这句，但判定函数只按标点认沉默，模型一照做，这句就被写到字幕条上念出来 |
| `package.json` 与 README 的许可标识改成 SPDX `MIT AND Apache-2.0` | 包里同时有 MIT 主程序和 Apache-2.0 的抓屏/判分代码，原来只写 MIT 与实际不符；README §十三 也改成把两部分说清楚 |

打包口径：包内文件数不变（17 个），没有新增运行时依赖。
